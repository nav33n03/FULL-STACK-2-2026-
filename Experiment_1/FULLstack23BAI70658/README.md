# 🌱 EcoTrack - Carbon Emission Tracker

> A modern, responsive web application to track and analyze carbon emissions from daily activities.

## ✨ Features

- 📊 **Real-time Dashboard** - View total carbon emissions at a glance
- 📋 **Activity Logging** - Track various activities and their carbon footprint
- 🎯 **Emission Categories** - Classify activities as high or low carbon impact

## 🚀 Quick Start

### Prerequisites
- Node.js (v14+)
- npm or yarn

### Installation

```bash
cd Experiment-1/Ecotrack
npm install
```

### Development

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Build

```bash
npm run build
```
